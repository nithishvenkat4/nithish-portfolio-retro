# Nithish V — Portfolio

A light, editorial-style personal portfolio built with React + Vite.

## Stack

- React
- Vite
- Framer Motion
- Lucide React
- Plain CSS

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite, usually:

```text
http://localhost:5173
```

## Production build

```bash
npm run build
```

## Preview production build

```bash
npm run preview
```

## Deploy

Recommended: push the project to GitHub and import the repository into Vercel.

Then add:

```text
nithish4507.me
```

as the custom domain in the Vercel project.

Do not change DNS until Vercel shows the exact DNS records required for the domain.

Replace or verify any project links, metrics, dates, and descriptions against the final resume/project repositories.
